# Homework 7 — JavaScript Interactivity

This page builds on Homework 3 without modifying that submission.

- Click **Show Next Tip** to cycle through four cybersecurity tips using a click listener.
- Type a learning goal to change the input's CSS class in real time; clear it to restore the original style.
- Select **Add Goal** (or press Enter) to create and append a list item.
- Select **Remove** to delete an item. Empty or whitespace-only goals are rejected.
- JavaScript is in script.js, loaded with defer. There are no inline event handlers.
- The list is temporary and resets on reload.

## Manual checks

Open index.html in a browser. Verify tip cycling, typing and clearing, adding multiple goals, rejecting blank input, removing items, keyboard navigation, and the browser console on load. Run WAVE on the new page before submission.
