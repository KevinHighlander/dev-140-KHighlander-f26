# Kevin Highlander — Portfolio Milestone 2

This milestone applies a shared visual system and responsive layouts to the three-page semantic HTML portfolio created for Milestone 1.

## Live site

`https://kevinhighlander.github.io/dev-140-KHighlander-f26/project-milestone-submissions/project-milestone-2/`

## Requirements demonstrated

- One linked `styles.css` file used across all three pages
- Google Font pairing: Space Grotesk for headings and Inter for body text
- Type, class, and ID selectors
- Consistent 8px-based spacing system with CSS custom properties
- Multi-column layouts using CSS Grid and Flexbox
- Mobile-first layout for 320px screens
- Media queries at 768px and 1200px
- Consistent navy, blue, off-white, and teal color palette

## Files

- `index.html` — Home
- `projects.html` — Projects / Work
- `about.html` — About / Contact
- `styles.css` — Shared styling and responsive rules

## Responsive testing

Tested at the assignment's required viewport widths:

- 320px — mobile
- 768px — tablet
- 1200px — desktop
