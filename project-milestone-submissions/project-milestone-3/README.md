# Kevin Highlander — Portfolio Milestone 3

This snapshot separates the accessibility and visual-design milestone from Milestone 2. The original graded submission used the Milestone 2 URL and received 75/75. The remote history preserves the WebAIM adjustment from November 4; the contact form in this snapshot is reconstructed because it was not present in the remote Milestone 2 files.

## Accessibility changes
- Replaced the redundant linked brand with a noninteractive brand on all three pages, preserving the main navigation.
- Added explicit labels, a fieldset and legend, required fields, native browser validation, an email hint, visible focus outlines and invalid-field styling to the contact form.
- The static site uses a mailto form; it does not have a server-side message service.

## Gestalt principles
- Proximity: project and skill cards are grouped into grids with consistent spacing.
- Similarity: cards use repeated typography, borders, color and spacing to make related items recognizable.
- The navy, teal, blue and off-white palette is shared across pages.
