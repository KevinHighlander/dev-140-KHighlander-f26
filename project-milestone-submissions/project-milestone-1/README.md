# Kevin Highlander — Portfolio Milestone 1

A three-page HTML-only student portfolio for DEV.140. This first milestone is focused on semantic structure, page headings, and relative navigation, **not CSS**.

## Files
- `index.html` — Home
- `projects.html` — Projects / Work
- `about.html` — About / Contact
- `wireframe.png` — wireframe sketch for all three pages, including the future color palette and fonts

## Preview
Open `index.html` in a browser and follow the navigation links between pages.

## Design plan for a later milestone
- Colors: deep navy (`#101B2D`), blue (`#2E6DA4`), off-white (`#F5F7FA`), and teal (`#14B8A6`)
- Fonts: Arial or another sans-serif font for headings and body text; monospace for small technical details if needed
- No stylesheets are used in this milestone.

## Privacy
This school portfolio should live in a separate repository from any private or personal programming projects. The projects page intentionally includes only coursework and general future-project descriptions.
